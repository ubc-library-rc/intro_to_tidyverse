This workshop presents some of the major packages in the tidyverse package in R.

<strong>If you want to code along, make sure to have <a href="https://cran.r-project.org">R</a> and <a href="https://posit.co/download/rstudio-desktop/">RStudio</a> installed </strong>

Download these two files and save them in the **same** folder:

- <a href="{{ '/files/sgvp_2023_workshop.csv' | relative_url }}" download>Download the data (sgvp_2023_workshop.csv)</a>
- <a href="{{ '/files/tidyverse_workshop.R' | relative_url }}" download>Download the R script (tidyverse_workshop.R)</a>

## Learning objectives

At the end of this workshop, you will be able to: 
1. Know what tidyverse is.
2. Understand the basics of data manipulation with tidyverse.

## What are we not learning today?

It is impossible to go through all tidyverse functions in detail. We are providing only a small snippet of what tidyverse can do!
